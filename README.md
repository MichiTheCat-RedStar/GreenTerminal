## Цель

Цель была в создании терминала на C с последующей компиляцией в бинарный файл для поддержки Windows и Linux.

Конкретная суть в том, что CMD Windows или Termianl Linux имеют разные синтаксис и много лишних для меня команд, либо команд, которые бы я никогда не использовал.

Данный терминал не имеет поддержки большинства функций, таких как команды системы, SSH, разного вида установщики пакетов и прочего.

Этот терминал создавался больше с целью углубления в язык программирования C, который был выбрал из-за своего удобного минимализма и поддержки компиляции в байтовые исполняемые файлы.

Для более успешной работы в разных системах здесь не будут файлы зависимостей, вроде локальных библиотек - только бинарный файл.

*Так же, на всякий случай, был добавлен [Python](/src/GreenTerminal.py) файл при проблемах с запуском бинарного файла, поэтому учтите, что python версия не является основной и может не поддерживать последние изменения или некоторые функции.*


## Запуск

- В [/bin](/bin/) находятся бинарники (скомпилированные файлы) под [Windows](/bin/windows/GreenTerminal.exe) и [Linux](/bin/linux/GreenTerminal).
- В [/src](/src/) находится [исходный код](/src/GreenTerminal.c) на C и [Python-аналог](/src/GreenTerminal.py) кода.
- Так же для использования в качестве своих отдельных проектов или форков на основе этого, стоит ознакомится с [лицензией](LICENSE).

**Просьба:** Стоит добавить бинарный файл в `PATH` или его аналог; Возможно в будущем это будет делаться автоматически или будет отдельный файл для добавления файла в `PATH`, но сейчас просьба добавить вручную.

### Команды

- `help`|`?` - выводит все команды
- `exit` - закрывает исполнение
- `data` - выводит дату
- `time` - выводит время в секундах
- `version` - выводит версию
